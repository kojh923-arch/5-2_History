# 5-2 사회 단원 정리 (5학년 2학기)

수업 자료 업사이클링 미션으로 만든 자기주도 학습 웹앱 모음입니다.

- `index.html` — 세 단원을 고르는 시작 화면 (사이트 루트)
- `unit1/index.html` — 1단원. 유적과 유물로 본 옛 사람들의 생활
- `unit2/index.html` — 2단원. 달라지는 시대, 변화하는 생활 모습
- `unit3/index.html` — 3단원. 식민 통치와 저항, 전쟁이 바꾼 사회와 생활

배포된 사이트에 접속하면 시작 화면에서 원하는 단원을 눌러 바로 이동합니다.
각 폴더의 `index.html`을 브라우저로 직접 열어도 실행됩니다.
